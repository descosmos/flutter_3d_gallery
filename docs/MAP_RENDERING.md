# 地图覆盖、清晰度与手势修复（2026-09-22）

| 用户问题 | 原因 | 当前实现 |
| --- | --- | --- |
| 扩大范围后旗杆落在地形外 | 固定 3×3 网格与照片筛选范围不同 | 从相机视野和可见照片位置计算覆盖；新网格与旗子一起替换，旗杆底端使用网格射线交点 |
| 地球放大后模糊 | 全尺度复用 2048×1024 地球纹理 | 近距离按屏幕分辨率加载卫星瓦片，贴到真实球面；最高 z18，地图渲染比例为 1.0 |
| 放大后轻触拖动就丢失旗子 | 固定每像素 0.22 度；缩放地心距离；抬指后重启单指旋转 | 按离地高度和视角计算位移，缩放离地高度并保持手指下地点；跟踪原始触点，全部抬起前不切回单指旋转；沿用旗面避让位置 |

共用实现为 `lib/gpu/map_tiles.dart`、`map_navigation.dart`。覆盖预算为最多 128 块：范围过大时降低瓦片级别，仍覆盖原范围；纹理缓存最多 160 块，并合并重复请求。地形页在手势期间按 120ms 间隔检查覆盖变化。最高放大时近裁剪面随离地高度收紧，防止深度精度不足造成旗面破损。

照片空间仍保留玻璃界面、固定地点相机和透明预览，地球远景保留星空。底图沿用现有卫星/标准服务，需联网；失败显示重试入口。DEM 原始精度未增加，广角视野会使用更粗的网格及底图级别。没有重测 FPS，不沿用此前 0.75 地图渲染比例的性能数据。
